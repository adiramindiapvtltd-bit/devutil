How this works & FAQ

Pick a text color and background color. The contrast ratio is calculated using the WCAG relative luminance formula. AA is the standard minimum for accessible web text; AAA is a stricter enhanced standard. "Large text" means 18pt+ (or 14pt+ bold).

What ratio do I need?

AA requires 4.5:1 for normal text and 3:1 for large text. AAA requires 7:1 and 4.5:1 respectively.
