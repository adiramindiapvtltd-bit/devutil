QR Code Generator

Turn text or a URL into a downloadable QR code. Runs entirely in your browser.

Type something to generate a QR code.
How this works & FAQ

Type any text or URL and a QR code appears instantly. Higher error correction levels make the code more resistant to damage or partial obstruction, at the cost of a denser pattern.

Is my content uploaded anywhere?

No. The QR code is generated locally using the qrcode-generator library, loaded once from a CDN — your text never leaves your browser.

What's error correction for?

It embeds redundant data so the code can still scan even if part of it is dirty, damaged, or covered by a logo.
