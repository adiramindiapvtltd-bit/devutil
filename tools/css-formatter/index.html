      How this works & FAQ
    
    

      
Paste CSS and click Beautify for readable, indented output with one declaration per line, or Minify to strip whitespace and comments for production.

      

        
Does minify remove comments?
Yes, Minify strips /* ... */ comments along with all unnecessary whitespace.

        
Does this handle SCSS or LESS?
It's built for plain CSS. Nested SCSS/LESS syntax and variables aren't parsed specially.
