      How this works & FAQ
    
    

      
Switch between Encode and Decode, and pick Binary (8 bits per byte) or Decimal (0–255 ASCII/UTF-8 byte values), space-separated. Works for any word, sentence, or block of text — including accented and non-Latin characters.

      

        
How do I convert text to binary code?
Type or paste a word or sentence into the box above with Encode and Binary selected — each character becomes its 8-bit binary byte, space-separated, instantly.

        
What's the difference between binary and decimal (ASCII) output?
Binary shows each byte as eight 0s and 1s (e.g. 01001000). Decimal shows the same byte as its ASCII/UTF-8 code number 0-255 (e.g. 72). Switch between them with the format toggle.

        
Can I convert binary back to text?
Yes — switch to the Decode tab, paste space-separated binary bytes (or decimal codes), and it converts back to plain text.
