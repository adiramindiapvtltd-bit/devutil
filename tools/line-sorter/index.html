      How this works & FAQ
    
    

      
Paste a list of lines and pick a sort order — the result updates as you type, no button click needed. Numeric sort extracts the leading number from each line; non-numeric lines sort to the end.

      

        
How do I sort lines alphabetically online?
Paste your list into the box above, leave Sort by set to A → Z (or Z → A for reverse), and the sorted list appears instantly. Turn off "Case-insensitive" to sort uppercase before lowercase.

        
Can I sort lines by number instead of alphabetically?
Yes — choose "Numeric" from the Sort by dropdown. It reads the leading number on each line and sorts by value; lines without a leading number sort to the end.

        
Does this line sorter remove duplicate lines?
No, it only reorders lines. Use the Duplicate Line Remover tool first if you also need to remove repeats.
