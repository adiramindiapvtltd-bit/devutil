      How this works & FAQ
    
    

      
Upload an image and it's resized to 16×16, 32×32, 48×48, 180×180 (Apple touch icon), 192×192, and 512×512 using the browser's canvas — download each size individually, then paste the HTML snippet into your page's <head>.

      

        
Is my image uploaded anywhere?
No. Resizing happens locally in your browser using the Canvas API — the image is never sent to a server.
